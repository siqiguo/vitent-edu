# AI 教育项目：商业模式与定价

*讨论稿 v0.1｜基于当前产品与课程设想*

**当前商业模型的核心：**以低价体验课完成首次付费和产品体验，以约 3,500 元的一年制系统课作为核心收入产品；教学主要由 AI Agent 完成，真人辅导老师负责规模化学习管理和必要干预；AI 使用量通过基础额度 + 超额增购控制成本；获客由自然增长、效果投放、渠道分销、直播/KOL 等多条渠道共同组成。

## 一、核心产品与定价

### 1. 正价系统课

当前倾向于把第一年的 AI 创作课程设计为完整系统课，约 50 节课、持续一年，整体售价区间暂定为 3,000–5,000 元，现阶段可先以约 3,500 元作为核心测算价格。

用户购买的不是单纯的视频内容，而是一整套 AI 驱动的学习服务，主要包括：

- 约 50 节项目制系统课程及相应教学内容。
- AI Agent 在课程中的全程讲解、互动、项目指导、反馈与复盘。
- 课程所需的 AI 创作能力和基础 Token / 生成额度。
- 一定额度的自由探索和课外创作能力。
- 真人辅导老师提供的学习进度检查、状态关注和必要人工干预。
- 作品保存、成长记录、社区发布与后续反馈等产品能力。

定价逻辑并不是按“视频课数量”计价，而是按一年完整的 AI 项目学习体验计价。

### 2. AI 使用额度：基础包含 + 超额增购

系统课价格中包含完成正常课程以及一定自由探索所需要的 AI 使用额度。孩子如果在课外进行大量图片、视频、音乐、代码等生成，超出基础额度后，可以通过额外购买 Token / 创作额度继续使用。

这样既保证孩子有足够自由探索空间，又避免少数高消耗用户导致 AI 成本失控。未来还可以把额外 Token 设计为创作积分、创作能量等更适合儿童产品的表达。

## 二、真人服务模型：AI 主教，真人负责学习管理和关键干预

真人老师不直接承担主要教学工作。课程讲解、互动、知识输入、项目分解、创作指导和大量反馈主要由 AI Agent 完成。真人辅导老师更像学习管理者或 Mentor，主要关注孩子是否持续参与、是否卡住、是否偏离目标，以及什么时候需要人工介入。

真人老师的主要职责可以包括：

- 检查学生的课程进度和活跃状态。
- 识别长期未学习、反复卡住或明显失去兴趣的学生。
- 必要时与孩子沟通，帮助重新建立项目目标和学习动力。
- 在 Agent 无法解决的问题上提供人工支持。
- 结合 AI 自动生成的学习摘要，快速理解每个孩子的近期状态。
- 必要时与家长沟通学习情况。

当前假设一个辅导老师可以服务约 300–400 名学生。这个模型成立的关键，是 AI 先完成日常监控和问题筛选，只把真正需要人工介入的学生和事件推送给老师，而不是要求老师逐个盯课。

## 三、初步单位经济模型

按照目前讨论的粗略假设：一名辅导老师包含工资、五险一金及相关综合成本约 15,000 元/月。如果服务 300 名学生，对应单个学生的人力服务成本约 50 元/月。

AI 成本目前暂按每节课约 10 元估算。如果平均每月约 4 节正式课程，则课程内 AI 成本约 40 元/月。再考虑一定自由探索额度，整体可先按约 100 元/学生/月的直接履约成本进行保守测算。

由此得到一个当前版本的粗模型：

- 正价课售价：约 3,500 元/年。
- 直接履约成本：约 100 元/月，即约 1,200 元/年。
- 单用户年度直接毛利：约 2,300 元。
- 对应粗略毛利率：约 65.7%。

如果真人服务效率进一步提高、模型推理成本继续下降，毛利率存在提升空间；如果视频生成等高成本能力使用明显增加，则需要依靠额度机制控制。当前 65%–70% 左右可以作为早期商业模型的目标区间，而不是已经验证的数据。

## 四、前端体验课：49 元完成首次付费和产品理解

为了降低用户第一次决策门槛，计划设计 1–2 节完整体验课程。目前倾向于 49 元包含两节课。

体验课不能是系统课的简化 Demo，而应该尽量保持与正式课程一致的核心结构：每节课都有明确项目目标，经历 AI 互动、知识输入、创作和反馈，并最终完成一个可以展示的作品。

两节体验课承担三个任务：

- 让孩子真实体验这种全新的 AI 项目制上课方式，并获得成就感。
- 让家长看到孩子实际完成的作品，而不是只听销售介绍课程。
- 积累孩子真实的学习和创作数据，为后续正价课推荐提供依据。

## 五、体验课到正价课的转化：尽量产品化，而不是依赖强销售

体验课结束后，希望尽量让家长自主完成正价课购买，而不是依赖传统教育行业高强度电话销售。

AI 可以在体验阶段自动形成一份面向家长的学习报告，例如：孩子完成了什么作品、表现出哪些兴趣和特点、在哪些环节投入度较高、有哪些可以继续发展的能力，以及如果进入一年系统课，未来会经历怎样的项目路径。

AI 还可以承担一部分课程顾问功能，回答家长关于课程结构、学习目标、AI 使用、老师服务、学习时间和作品成果等问题。真人销售只处理更复杂的问题或高意向用户。

理想的转化逻辑是：家长先看到孩子真实的体验和成果，再理解一年学习路径，最后自主做出购买决定。这样既有可能降低销售成本，也更符合产品本身强调 AI Native 的方向。

## 六、获客模型

目前计划同时建立多种获客渠道，但最终都尽可能导向低价体验课或直接正价课购买。

### 1. Organic Growth / 有机增长

有机增长包括用户口碑、作品分享和转介绍。每节课都有作品，因此作品本身天然具有传播属性。孩子可以把作品分享给朋友、同学和家长社交圈，从而形成潜在的新用户入口。

同时可以建立转介绍激励：老用户成功推荐新用户购买后，获得积分、Token、创作额度、课时或其他权益。相比单纯现金返现，更倾向于把奖励重新投入孩子的学习和创作。

### 2. 效果广告投放

可以通过信息流广告等效果渠道售卖 49 元体验课。体验课价格较低、产品结果可视化，适合作为广告前端品。核心需要持续验证的是前端获客成本、体验课完课率、体验到正价课转化率以及最终正价 CAC。

### 3. CPA / 私域渠道

可以与拥有家长流量或教育用户资源的私域渠道合作，以 CPA、CPS 或其他效果结算方式售卖体验课或正价课。

### 4. 分销渠道

与教育渠道、经销商或其他合作方建立分销机制，由合作方销售正价课程并获得一定比例返佣。具体佣金率需要结合最终毛利和渠道获客效率测算。

### 5. 直播销售

通过自营直播销售体验课和正价课。由于产品具有很强的视觉成果属性，可以在直播中直接展示孩子如何与 AI 互动、如何完成作品以及最终成果，相比抽象介绍教育理念更容易建立理解。

### 6. KOL / 达人合作

与教育、亲子、科技、AI 等领域的头部或垂类 KOL 合作，由达人完成内容种草、直播或课程推荐，并通过佣金分成等方式结算。

## 七、最值得关注的增长飞轮：作品本身成为获客媒介

这一产品与传统课程一个潜在的重要差异，是每节课都会产生可传播的作品。孩子学习的结果不是一张分数单，而是角色、绘本、动画、音乐、游戏、App 或其他作品。

因此可以形成一个潜在飞轮：孩子学习 → 产生作品 → 发布和分享 → 获得反馈与成就感 → 吸引其他孩子和家长 → 进入体验课 → 成为新用户 → 继续产生作品。

如果这一飞轮能够成立，Organic Growth 有机会逐步降低整体 CAC，并形成课程内容、创作社区和商业增长之间的协同。

## 八、续费问题：目前最需要继续设计的商业环节

当前商业模型中最不确定的部分不是第一年获客，而是第一年之后用户为什么继续付费。第一年的 AI 创作课可以形成非常清晰的购买理由，但如果第二年只是再卖一套“高级 AI 创作课”，很容易重新回到传统课程不断分级续费的逻辑，也不足以承接项目的长期愿景。

因此，续费产品应该从“AI 创作”逐步走向更完整的项目制学习体系。AI 创作只是孩子进入新学习方式的第一阶段，后续项目开始自然覆盖更多能力：数学、科学、语言表达、社会理解、商业、工程、计算思维等。

创作者社区可以成为长期底层设施和用户留存机制，但不应该成为整个产品的最终终点。长期核心仍然是：用 AI + Project 的方式覆盖越来越完整的知识和能力学习。

## 九、一个可能的长期课程 / 续费结构

目前出现了一个值得继续探索的结构：把 Project 作为比“单节课”更高一级的学习单位。一个大型 Project 可以持续约三个月，一年完成约四个 Project。每个 Project 内再拆成约 10–13 节课或多个阶段。

这样，第一年的约 50 节 AI 创作课也可以重新理解为四个连续的大型 Project，而不是 50 个彼此独立的小作品。四个 Project 之间形成明显的能力递进。

例如第一年可以从“把脑海里的想法变成现实”出发，逐步经历角色、世界、故事、动画、音乐、交互、游戏或应用等创作能力。第二年开始，则从“创造想象世界”进一步走向“理解并改变真实世界”，进入未来城市、经营公司、科学调查、工程设计、火星基地等跨学科综合项目。

如果这条路径成立，续费就不再是简单购买下一等级课程，而是进入下一阶段的能力成长与 Project 体系。具体项目序列、能力递进和第二年定价仍需要后续重点设计。

## 十、当前商业模型简图

获客渠道（Organic / 广告 / CPA私域 / 分销 / 直播 / KOL） → 49 元两节体验课 → 孩子完成真实作品 → AI 生成学习与成长报告 → AI 辅助家长理解系统课 → 自主购买约 3,500 元一年系统课 → AI Agent 主教学 + 真人 Mentor 规模化服务 → 作品持续产生并进入社区和分享 → 带来自然增长 → 第一年度完成多个 Project → 进入更综合的下一阶段 PBL 课程。

## 十一、下一步需要验证的关键参数

- 3,500 元是否是最优价格点，还是应在 2,999 / 3,499 / 3,999 / 4,999 等价格带测试。
- 49 元两节体验课的付费率、完课率和正价转化率。
- 真人 Mentor 1:300–1:400 的服务模型能否真实跑通。
- AI 每节课 10 元的成本假设，以及视频、音乐、代码等不同项目的成本差异。
- 基础 Token 应包含多少，超额增购如何定价。
- AI 销售顾问能够替代多少传统销售工作。
- 不同获客渠道的 CAC、回收周期和规模上限。
- 作品分享和转介绍能够贡献多少 Organic Growth。
- 第一年结束后的续费产品、Project 体系与合理定价。
- 社区究竟对留存、续费、获客分别能贡献多大价值。
