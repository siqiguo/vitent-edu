# Vitent Edu 文档目录

项目文档按用途分为课程设计、研究分析和原始资料三类。

| 目录 | 用途 | 内容 |
| --- | --- | --- |
| [curriculum-design](curriculum-design/) | 课程与学习体验设计 | 项目构想、课程结构、教学流程 |
| [research-analysis](research-analysis/) | 研究与决策支持 | 标准分析、市场调研、商业模式 |
| [source](source/) | 原始资料归档 | 项目原稿、中美课程标准、国际能力框架 |

## 维护约定

1. 可编辑的设计文档和分析文档分别放入对应目录。
2. 下载或收集的原始文件只放入 `source/`，不直接改写。
3. 分析稿引用原始资料时使用相对链接，确保本地和 GitHub 均可访问。
4. 同一主题的原文与分析稿可分处不同目录，但应在索引中互相链接。
