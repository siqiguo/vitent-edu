# AI 项目制课程：单节课结构设计

*讨论稿 v0.1｜9–12 岁 AI 创作系统课*

**核心原则：**每节课从一个具体的创作任务出发，通过“引入 → 知识输入 → 互动理解 → 创作意图形成 → 分步创作 → 反馈迭代 → 成果发布 → 总结沉淀”形成完整闭环。AI Agent 贯穿全程，不只是讲解者，更是理解孩子想法、观察学习过程、提供反馈并推动迭代的学习伙伴。

## 一、单节课的总体目标

每节课都应该让孩子完成一个明确、可展示的作品。课程不是以“学会几个 AI 功能”为终点，而是让孩子为了完成自己的作品，在过程中学习必要的知识、方法和 AI 能力，并逐渐形成自己的表达。

- 有一个清晰的项目目标或待解决的问题。
- 完成必要但不过量的知识输入。
- 通过互动确认孩子是否理解，并创造表达机会。
- 由孩子形成自己的创作方向，而不是直接接受标准答案。
- 在 Agent 陪伴下分步骤完成作品，并不断判断、调整和迭代。
- 形成可保存、可展示、可分享的最终成果。
- 在课程结束时沉淀本节课的知识、过程和作品。

## 二、单节课完整流程

### Step 1｜AI 互动引入：从上一课进入今天的挑战

课程首先由 AI Agent 通过语音等自然交互方式与孩子交流。它可以简短回顾上一节课完成了什么、学到了什么，并自然引出今天的新任务。重点不是传统意义上的“老师宣布教学目标”，而是让孩子理解：今天我们要解决什么问题，或者一起完成一个什么样的作品。引入需要建立期待感，让孩子知道这一节课最终会得到什么。

### Step 2｜第一轮动画知识输入

进入一段短动画内容。动画承担第一组必要知识、基本原理或方法的输入，同时增强趣味性。它不追求一次讲完整套知识，而只讲接下来完成项目真正需要的内容。单段动画与后续互动合计可控制在约 2–3 分钟的短节奏内。

### Step 3｜第一轮互动理解与表达

动画之后立刻进入互动。题型可以包括选择、连线、排序、情景判断、拖拽等，也可以穿插 AI 语音交互。互动有两个目的：一是检验孩子是否理解刚才的输入；二是尽早让孩子开始表达，而不是一直处于被动观看状态。Agent 可以根据回答情况判断是否需要补充解释或改变后续引导方式。

### Step 4｜第二轮动画 + 互动

如果本节项目需要两个不同维度的知识或方法，可以再进行一轮“短动画 + 互动”。两轮知识输入都应该服务于后面的创作，而不是为了覆盖知识点而增加内容。整体上保持短输入、高互动的节奏。

### Step 5｜Agent 小结，并帮助孩子形成自己的创作意图

完成两轮学习后，Agent 再次进入较完整的语音交流。它先简要总结刚刚学到的知识，也可以结合孩子在互动题中的表现做针对性沟通。随后课程从“学习别人讲的内容”正式转向“我要做什么”：Agent 与孩子讨论他想创作什么、希望是什么风格、想表达什么、希望最终达到什么效果。通过追问、澄清和复述，帮助孩子把一个模糊想法逐渐变成相对明确的创作目标。这里非常关键：Agent 应帮助孩子表达自己的想法，而不是替孩子决定。

### Step 6｜进入实际创作：把大任务拆成若干步骤

明确创作目标后进入实际操作平台。整个作品被拆解成若干可完成的步骤，每一步开始时由 Agent 做必要的操作指导和方法提示，然后交给孩子自己完成。创作平台可以根据课程不同而变化，例如角色设计、绘本、动画、音乐、游戏或 App 创作环境。

### Step 7｜每一步都形成“行动—观察—判断—调整”的小循环

孩子完成一个步骤后，Agent 不应立刻替他进入下一步，而是围绕结果继续交流，例如：你对现在的结果满意吗？哪里和你最开始想的不一样？你希望怎么调整？如果孩子满意，就进入下一步；如果不满意，就帮助他继续修改。这样把“生成一个结果”变成“形成判断并不断迭代”的过程。

### Step 8｜完成作品后的整体反馈与再次迭代

当所有操作步骤完成后，孩子得到一个相对完整的作品。Agent 与孩子一起回看作品，并给出反馈。反馈不应该只是简单评价好或不好，而应更多围绕孩子最初的意图、作品是否表达出来、哪些部分有特点、哪些地方还可以继续发展。孩子可以选择立即修改，也可以把建议留到下一次创作中。最终形成一个孩子自己认可、相对满意的版本。

### Step 9｜作品发布与分享

最终作品可以发布到产品内部的创作者社区，也可以生成适合分享到朋友圈、社交群或其他社交媒体的形式。发布的意义不只是展示成果，更是让孩子逐渐进入“创作—发布—获得反馈—继续迭代”的真实创作者循环。社区机制后续需要单独设计，尤其要考虑儿童安全以及避免单纯以点赞数量定义作品价值。

### Step 10｜AI 自动生成课程总结 / 作品档案

课程结束后，AI 可以自动生成类似 PPT、作品册或学习卡片的总结内容。它把这节课学到的关键知识、孩子在过程中形成的主要想法、创作步骤、最终作品以及值得继续探索的问题整合起来。这个总结既是给孩子的复盘，也是长期成长档案的一部分，还可以成为孩子向家长展示“今天到底学了什么、做了什么”的载体。

## 三、单节课的核心节奏

**回顾与挑战引入 → 短动画 → 互动 → 短动画 → 互动 → Agent 对话形成创作意图 → 分步创作 → 每步反馈迭代 → 完整作品 → 总体反馈 → 发布分享 → AI 总结沉淀**

从学习体验上看，这一结构刻意避免长时间单向输入。动画输入保持短小，互动紧随其后；真正占据课程主体的应该是孩子自己的思考、表达和创作。随着课程阶段提升，前端知识讲解的比例甚至可以逐步降低，孩子自主定义目标和创作的比例逐步提高。

## 四、Agent 在一节课中的角色变化

- 开场：连接者——连接上一节课与今天的新挑战。
- 知识阶段：讲解者与诊断者——提供必要输入，并判断孩子理解程度。
- 创意阶段：访谈者与启发者——通过交流帮助孩子把自己的想法说清楚。
- 创作阶段：教练——提供步骤、方法和操作支持，但不替孩子做关键决定。
- 迭代阶段：反馈伙伴——帮助孩子观察结果、形成判断、继续修改。
- 结束阶段：复盘者与记录者——总结知识、作品和成长过程，并形成学习档案。

## 五、这一结构背后的教学原则

**从作品出发，而不是从知识点出发：**孩子首先知道自己要完成什么，知识在项目需要时出现。

**短输入、高互动：**尽量避免长时间观看，让孩子不断做选择、回答、表达和操作。

**表达先于技巧：**AI 技能的价值是帮助孩子实现自己的意图，而不是让孩子机械掌握工具。

**Agent 不替代孩子：**Agent 的目标是让孩子越来越能自己想、自己判断、自己修改，而不是替孩子生成一个看起来很漂亮的作品。

**允许不满意和反复修改：**作品不是一次生成的结果。课程需要主动创造修改机会，让孩子习惯迭代。

**每节课形成可见成果：**作品、总结卡和成长记录共同建立成就感，并为长期学习留下轨迹。

## 六、后续需要继续明确的问题

- 单节课总时长，以及动画、互动、Agent 对话和创作各自的时间比例。
- 两轮知识输入是否作为标准结构，还是根据项目动态变化。
- 语音 Agent 与屏幕操作之间如何切换，避免孩子频繁中断创作。
- Agent 的反馈策略：什么时候直接提示，什么时候追问，什么时候保持沉默。
- 如何判断孩子已经形成了自己的创作意图，而不是跟随 AI 的建议。
- 不同类型项目需要哪些专用创作工具和操作环境。
- 课程总结 PPT / 作品册具体包含哪些内容，以及是否同时面向孩子和家长。
- 社区发布、外部分享、隐私和儿童安全机制。
