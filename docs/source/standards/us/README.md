更新日期：2026-09-11

## 仅保留官方入口的补充标准

以下资料与项目相关，但没有将文件副本收入仓库：

- [C3 Framework for Social Studies](https://www.socialstudies.org/sites/default/files/c3/c3-framework-for-social-studies-rev0617.pdf)：覆盖公民、经济、地理、历史，按 K–2、3–5、6–8、9–12 给出探究路径。官方 PDF 可在线读取，但其服务器在本次归档时拒绝直接下载。
- [ISTE Standards for Students](https://iste.org/standards/students)：数字公民、知识建构、创新设计、计算思维、创造性沟通与全球协作。该框架跨年龄使用，不是逐年级内容标准；官方 PDF 下载需要提交邮箱并同意教育用途，因此未绕过流程保存副本。
- [SHAPE America 2024 National PE Standards](https://shapeamerica.org/standards/pe/new-pe-standards/)：按 PreK–2、3–5、6–8、9–12 提供体育学习指标。完整 PDF 通过受控下载入口提供，因此本目录仅记录公开标准页面。

## 使用建议

对 AI 项目制课程进行能力映射时，可优先采用以下组合：

1. 用 Common Core ELA/Literacy 标记阅读、写作、表达、讨论、研究和证据使用能力。
2. 用 Common Core Mathematics 标记数量关系、建模、数据和问题求解能力。
3. 用 NGSS 的 Science and Engineering Practices 标记提问、建模、调查、分析、论证、设计和沟通能力。
4. 用 2026 CSTA 标记计算思维、编程、数据、系统安全、AI、伦理和人本设计能力。
5. 用 NCAS Media Arts 标记创意形成、制作、迭代、呈现、评价和文化连接能力。
6. 面向多语言学习者时，用 WIDA 同时设计学科目标和语言表达目标。
