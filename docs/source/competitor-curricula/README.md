## 可用性说明

- `international/day-of-ai/` 中的页面构成 2026–27 学年新版逐年级课程快照。
- Machine Learning for Kids 的项目清单来自 Apache-2.0 授权的官方资料仓库；本目录仅保存说明与文件索引，没有批量复制全部工作表。
- 商业机构往往只公开阶段或产品模块，不公开完整课次。分析稿对缺失信息统一标为“未公开”。
- Ai2Kids 的公开页面同时出现“50 集”和“100 集/100 个主题卡”等表述，归档时保留原始页面与前端资源包，以便复核版本差异。
